# Week 3 - Python OOP Assignments

This repository contains my Week 3 Python assignments focused on Object-Oriented Programming (OOP) and exception handling.

## Assignments

### 1. Bank Account Class
A Python class implementing:
- Deposit
- Withdrawal
- Balance display
- Positive amount validation
- Insufficient funds handling

### 2. Library Management System
An OOP-based library system implementing:
- Add books
- Remove books
- Issue books
- Return books
- Display library catalog

### 3. Calculator Class
A calculator class implementing:
- Addition
- Subtraction
- Multiplication
- Division
- `ZeroDivisionError` handling
- `TypeError` handling

### 4. Billing System - Mini Project
An OOP-based billing system implementing:
- Product name, price, and quantity
- Product subtotal calculation
- 5% tax calculation
- Final total calculation
- Tabular bill display

## Files

- `index.html` - GitHub Pages project homepage
- `bank account.py` - Bank Account assignment
- `library management.py` - Library Management assignment
- `calculator.py` - Calculator assignment
- `billing system.py` - Billing System mini project

## How to Run

Make sure Python 3 is installed.

Run any assignment from the terminal, for example:

```bash
python "bank account.py"
python "library management.py"
python calculator.py
python "billing system.py"
```

No external Python packages are required.

## GitHub Pages

If GitHub Pages is enabled from the `main` branch and `/ (root)` folder, the project homepage can be published using `index.html`.
